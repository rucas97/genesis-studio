# GENESIS Studio

> A three-mode living genome environment with an Emergence Engine for observing complex disease in silico.

**Research-use-only. Not a medical device.**

## What it is

GENESIS Studio is a single application with three modes that share one state:

- **Play** — a real-time 3D molecular sandbox. Grab proteins, mutate residues, splice genes, dock ligands, run simulations by hand.
- **Flow** — a node-based bioinformatics pipeline environment. Drag tools, connect them, run at scale, reproduce everything.
- **Emergence** — a long-timescale multi-scale simulator where complex disease phenotypes emerge and are observed, not predicted.

An AI co-scientist watches all three modes, cross-validates every prediction, checks every result against human knowledge, and produces structured, falsifiable hypotheses.

## The central claim

Complex disease is an emergent phenomenon. It cannot be predicted from a formula. It must be simulated and observed. The Emergence Engine is the first instrument built for that observation.

## Honest scope

- v1 is one protein, one mutation, one pipeline, one bridge.
- Complex disease prediction is not solved and is not claimed.
- Every output is a hypothesis, not a fact. Wet-lab validation is mandatory.
