# @genesis/emergence

Multi-scale, long-timescale, stochastic simulation engine.

- `scales/` — Molecule, complex, pathway, cell, tissue, organ, organism
- `acceleration/` — Neural surrogates, learned coarse-graining, physics constraints
- `detection/` — Disease signatures, critical transitions, causal chains
- `intervention/` — In silico intervention testing
- `state/` — Emergence-mode state slice

## Central claim

Disease is emergent. We do not predict it. We observe it.
